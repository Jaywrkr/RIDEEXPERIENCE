# Sitio de registro

Sitio público de inscripción a un evento. Sin build step ni dependencias
— HTML/CSS/JS plano, PWA instalable (manifest + service worker adaptados
de `../shineray-deck/`).

Antes de desplegar, editar `js/config.js` (URL del backend y, opcional,
ID del evento). Ver
[`../docs/PENDIENTES_CLIENTE.md`](../docs/PENDIENTES_CLIENTE.md) para la
lista completa de lo que falta configurar.

Corresponde a la Semana 3 del plan — ver
[`../docs/SEMANA_3.md`](../docs/SEMANA_3.md).
